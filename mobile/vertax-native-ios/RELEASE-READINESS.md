## Local behavior

- Live progress is stored separately from the crate and draft. Set and Free keep their own cue order and played position. The timer counts wall-clock time while active, including time outside the foreground, and freezes on explicit pause or when the current queue finishes.
- The down chevron pauses and keeps progress; **End** clears progress, not the draft. Removing the draft while paused does not touch the live queue. The confirmed **Clear local data** action clears both.
- Live suggestions only extend the current Set queue. Existing library data and backup format are unchanged. JSON backups and TXT exports do not include Live progress.
- A malformed JSON backup is rejected before a merge. Local state uses separate keys for the crate, draft, saved sets, wishlist, and Live progress. An unreadable value falls back to that store's defaults on load, without rewriting it at startup. This is not partial recovery: a later save can replace the unreadable value, so an exported backup remains the recovery path.
